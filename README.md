# Kedi Miyav Selamlaşma Protokolü

## Resmi Tanıtım

Bu repository, **insan-kedi diplomatik ilişkilerinde** devrim yaratan, tamamen çalışan bir protokoldür. 
Yıllar süren (asılında 5 dakikalık) araştırmalar sonucunda, kedilerin anladığı tek dil olan **Miyavca** ile 
resmi selamlaşma standartları belirlenmiştir.

### Neden Bu Protokol?

- Kediler artık "miyav" demekle yetinmiyor. Resmi bir protokol istiyorlar.
- Uluslararası Miyav Standartı (UMS-2026) ile uyumludur.
- Gerçekten çalışır. Deneyin, kediniz etkilenecek (veya etkilenmeyecek, o da bir başarı).
- Abartılı ciddiyet ile yazılmıştır çünkü kediler şakadan anlamaz.

### Kullanım

```bash
python kedi_protokol.py
```

Program sizden bir selam ister, sonra onu uygun sayıda miyava çevirir. 
Miyav sayısı, girdi uzunluğuna göre matematiksel olarak hesaplanır. 
Bu bir bilimdir.

### Özellikler

- Rastgele miyav seçimi (Miyav, Miiyav, Purr vs.)
- Dramatik bekleme süreleri (kediler acele etmez)
- Memnuniyet yüzdesi hesaplama
- Gizli diplomatik notlar (kodun içinde saklı)

### Katkıda Bulunma

Pull request açabilirsiniz ama kediler onaylamadan merge edilmez.
Issue açarsanız, miyav dilinde yazın.

### Lisans

Bu protokol kamuya açıktır. Kediler ücretsiz kullanabilir.
